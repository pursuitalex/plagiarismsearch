How PlagiarismSearch Works in Canvas

PlagiarismSearch connects to Canvas through an LTI 1.3 document processing integration. Once the app is installed and enabled for an eligible assignment, submitted work can be checked as part of the existing Canvas workflow.

  1. 01

    Connect the integration

    A Canvas administrator installs PlagiarismSearch using Dynamic Registration and makes the app available in the appropriate Canvas account or courses.

  2. 02

    Enable assignment checking

    An instructor adds PlagiarismSearch as a document processing app to an eligible assignment and configures the available checking options.

  3. 03

    Students submit their work

    Students complete their assignments using Canvas File Uploads or Text Entry. The submission is sent for processing when the integration is enabled.

  4. 04

    Review the results

    After processing, instructors can see the returned similarity and AI-writing indicators, when available, in SpeedGrader and open the corresponding detailed reports.

Plagiarism Checking and AI Writing Detection Are Separate Analyses

Plagiarism and AI-generated writing are different questions. PlagiarismSearch provides separate analyses so instructors can consider each result for its intended purpose.

Plagiarism Checking

Identify matching or similar passages in submitted work and review the sources associated with those matches.

Similarity findings can help instructors examine quotations, citations, reused material, and passages that may require closer attention. A match does not automatically mean that plagiarism has occurred.

AI Writing Detection

Analyze text for patterns associated with AI-generated writing when the AI-checking feature is enabled.

The resulting AI probability indicator can support further review, but it does not establish who wrote a document or whether academic misconduct occurred.

Two separate results. One informed review process.

Check File Uploads and Text Entry Assignments

PlagiarismSearch supports two common Canvas assignment submission types.

File Uploads

Students can submit supported documents through Canvas assignments. PlagiarismSearch processes eligible files and returns the available checking results for instructor review.

Text Entry

Students can also submit text directly in Canvas. Supported Text Entry submissions can be processed without requiring students to create a separate document for upload.

Both submission types are part of the existing Canvas assignment workflow. Actual file acceptance depends on the supported formats and applicable Canvas settings.

Configure Checking and Report Access

Understand How Submitted Work Is Handled

Checking submitted work and storing it for future comparisons are separate parts of the workflow.

  1. 01

    Submission processing

    When an eligible assignment uses PlagiarismSearch, supported submitted content is transferred for the configured analysis.

  2. 02

    Report generation

    PlagiarismSearch processes the submission and returns the available results to Canvas. Detailed reports can be accessed through their corresponding links.

  3. 03

    Storage configuration

    Whether a submission is retained in PlagiarismSearch Storage for future comparisons depends on the applicable storage settings. Processing a submission does not, by itself, mean that the document becomes a permanent comparison source.

Institutions should review their integration settings and applicable data-handling policies before deployment.
