Workflow

How the PlagiarismSearch API workflow works

1

Submit

Send text or a public URL as JSON, or upload a document with multipart form data.

2

Configure

Select the search sources and options required for the check and provide the callback_url where completion events should be sent.

3

Process

The API creates the report and returns a 202 response with the report ID while plagiarism checking continues asynchronously.

4

Receive

When processing is complete, PlagiarismSearch sends a report.checked webhook to your callback URL. Use the report ID and returned report link to continue the workflow inside your own system.

Your integration does not need to wait for the plagiarism check to finish before continuing other work.

The initial response identifies the report, and the completion webhook tells your system when the check is ready.
